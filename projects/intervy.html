Intervy

An AI-powered technical interview coach for Claude Code: assignment review, live coding, algorithm challenges and a full round-table panel simulation.

View on GitHub

Why I built it

Preparing for technical interviews usually means jumping between LeetCode, mock-interview sites and notes. Intervy brings all of that into the terminal: you type interview in a Claude Code session and it runs a realistic, scored interview, calibrated to your seniority, on your own code or on a freshly generated scenario.

Four interview modes

Assignment Review

Paste a project or a git URL. Intervy questions you on architecture, failure modes, security, testing and production readiness. Scored 0–100.

From Scratch

Build a back-end API under time pressure, FAANG-style, in Python (FastAPI/Flask) or Java Spring Boot, on a randomised business scenario.

Coding Challenge

LeetCode-style algorithm practice with hints on demand and edge-case testing. Scored 1–10 with complexity and code-comment analysis.

Round-Table

Face a panel of 7: handler, HR, manager, tech lead, architect, senior dev and CTO, each with a random personality that changes how they question and score you.

How it works

Intervy is a set of five cooperating Claude Code skills:

  1. intervy: the entry point. It picks up "interview" or "practice" and walks you through choosing a mode.
  2. intervy-scenario: generates a randomised company and business scenario, shared by the From Scratch and Round-Table modes.
  3. intervy-questioner: fires language-specific deep-dive theory questions between rounds.
  4. intervy-technical: runs the 7-panelist round-table, with the personality system and dynamic follow-ups.
  5. intervy-score: evaluates each round and merges the panel into a final verdict.

Try it

You need Claude Code installed. Then install the skills globally:

git clone https://github.com/ieCecchetti/intervy /tmp/intervy-install
cp -r /tmp/intervy-install/.claude/skills/* ~/.claude/skills/
rm -rf /tmp/intervy-install

Open Claude Code in any project and type interview.
